# 独立 Arduino 气囊控制：当前为定时测试

新的上电全关、串口收命令台架草图见 [09_airbag_command_bench](../09_airbag_command_bench/README.md)。本 `07` 草图上电即循环，不能用于阈值联动或佩戴气囊。

打开同名 `07_airbag_control_arduino.ino`，在 Arduino IDE 中按实际开发板选择 Arduino Uno 或对应的 Nano 型号，再选这块 Arduino 自己的端口。它与现有 ESP32 传感器程序是两个独立草图，上传到 Arduino 不会修改 ESP32 上的程序。

| 设备 | Arduino 引脚 | 控制 |
|---|---|---|
| 电磁阀驱动输入 | D3 | 数字开/关 |
| 充气泵驱动输入 | D4 | 仅全速开/关 |
| 抽气泵驱动输入 | D5 | PWM，默认 255 |

按用户提供的控制板示例保留 D3/D4/D5。经典 Uno/Nano 的 D4 不支持 PWM，所以充气泵在这份草图里只能全速开/关。照片显示气泵控制板是集成板，不应假定把程序里的 D4 改成 D6 就能让板上充气泵调速；需要确认内部走线与驱动能力。原示例的 `PIN_INFLATE`/`PIN_VALVE` 名称和所控设备互换，这里也已改正。

程序上电后执行 3 次循环：电磁阀打开并充气 8 秒 → 电磁阀关闭并抽气 8 秒 → 全部停止；完成后保持停止。按复位键会重新执行。修改文件开头的 `CYCLE_COUNT`、`INFLATE_MS`、`DEFLATE_MS` 可调整次数和时长，`DEFLATE_SPEED` 可调整抽气泵 PWM。电磁阀和 D4 充气泵始终只用 `digitalWrite` 开关。

此草图假设驱动模块为**高电平启动**、低电平关闭；如果实物是低电平启动，须按模块说明调整控制逻辑后再通电。Arduino 引脚只接驱动模块的控制输入；气泵和电磁阀须使用符合电压、电流要求的独立驱动、电源及续流保护，并共地。正式接气囊前先核对阀门气路：此程序在抽气时关闭阀门，若关闭后堵住抽气路径，需要依据实际气路修改阀门动作。代码只有定时控制，没有压力反馈或过压保护。

## 为什么与传感器分开，仍能被传感器触发

建议保留两个独立硬件子系统：**ESP32 + 压力条/IMU/ECG** 负责采集；**Arduino Uno + 气泵/电磁阀控制板** 负责执行。两块开发板各自有固件和电源/驱动接线。它们通过电脑上的程序交换**数据和控制命令**：

`三路传感器 → ESP32 → 电脑接收、分析和人工确认 → 另一条 USB 串口 → Arduino Uno → 气泵/电磁阀 → 气囊`

“分开”指传感器线和泵驱动不接到同一套控制板上，并不妨碍电脑把分析结果发给 Uno。这样也便于分别调试采集和执行；泵的供电与开关噪声不会直接走传感器板的供电/信号线。两板分开本身不等于整机电气隔离，仍须核对电源、保护和人体接入方案。

**当前还没有实现这条自动触发链。** 新增的 ESP32 `08_sensor_sync` 固件已上传实板，电脑端「三通道同段观察」已完成未接人体的 USB 三路采集，可显示约20秒整段的候选越线；还没有同步人体或发作样本。旧的 `05_sensor_switch` 和 `06_sensor_wifi` 固件仍一次只采一个模块，历史分开测量不能合成“同时异常”。电脑端目前没有发给 Uno 的气囊命令，当前草图上电即做固定循环，只供脱离人体的台架定时测试。正式联动还需验证短时窗口、持续时间、失联停止和气路/压力保护；不能把约20秒整段界线直接缩短成几秒的自动触发阈值。

## 照片中的接口核对

三张照片（`IMG_7378.HEIC`、`IMG_7379.HEIC`、`IMG_7380.HEIC`）显示气泵控制板叠在下层开发板上。**下层板前缘的 USB-C** 是应连接电脑、供 Arduino IDE 编译上传和串口通信核对的接口；**上层气泵控制板前缘的 Micro-USB** 和两层板各自的圆形 DC 插孔都不能当成下层板的程序上传口。上层 Micro-USB 的具体供电作用与额定值仍需板卡型号或说明书核实，不能与 DC 电源同时随意接电。

2026-11-02 电脑检测到 `/dev/cu.usbserial-130`，USB 设备描述为通用的 `1a86:7523 USB Serial`；该描述能确认存在 USB 串口，但不能独立证明下层板的具体型号，也不能从软件确认用户把线插在哪个物理插孔。连接下层 USB-C、重新插拔后观察此端口随之消失/出现，才能把物理口和串口对应起来。当前没有打开串口、上传或启动气泵。

照片仍没有清晰展示完整型号、底板主控芯片和气泵板内部走线。不能凭黄色/红色/黑色排针颜色推定电压、GND 或信号。D3/D4/D5 来自用户给的示例程序，尚未由照片核实与这块控制板的实际走线相符。接线前需读取板上型号和清晰丝印，核对供电额定值、控制输入、阀门通断气路与实际所用 Uno 型号。

## 三传感器检测：当前可做与尚缺的部分

当前 Demo 能分别采集三种传感器，并用已保存的正常记录离线讨论候选变化提示；现有记录可继续用于课程中的单模块验证和流程演示，不必为了展示概念立刻重测整批数据。若用旧数据做三路决策演示，必须标注为**历史记录回放/模拟联动**，不可称为真实同时检测或已验证的自动气囊触发。

如果课程要求同一次佩戴、同一时刻的三路传感器结果实时决定是否触发，现在已备好同步采集固件和电脑接收代码，但还需在实板上核对时间、采样率与数据质量，并采集同步正常和动作数据。现有 05/06 固件一次只采一路，三次分开测得的结果不能直接当作同一事件的三路证据。现有候选值仅支持变化提示与人工确认，尚未建立自动启动佩戴气囊的有效临界值。
